## ✅ 项目名称：融销通（rongxiaotong）
这是一个集 **农业物联网、金融服务、电商交易、专家服务、市场行情、用户管理** 于一体的智慧农业综合服务平台。

# 📚 二、每张表详细结构与字段说明

---

### 1. `amqp_message` —— AMQP 协议消息接收日志
用于记录从华为云 IoT 平台通过 AMQP 协议推送过来的原始消息。

| 字段         | 类型     | 含义                   |
| ------------ | -------- | ---------------------- |
| `id`         | bigint   | 主键                   |
| `device_id`  | varchar  | 设备ID                 |
| `service_id` | varchar  | 服务ID（如环境监测）   |
| `event_time` | datetime | 事件时间               |
| `paras`      | json     | 参数（温度、湿度等）   |
| `event_type` | varchar  | 事件类型（如数据上报） |
| `ts`         | datetime | 时间戳                 |

> 📌 用途：物联网平台与后端通信的中间日志，便于排查设备通信问题。

---

### 2. `iot_device_message` —— 物联网设备数据表
存储解析后的设备采集数据。

| 字段               | 类型     | 含义                |
| ------------------ | -------- | ------------------- |
| `id`               | bigint   | 主键                |
| `device_id`        | varchar  | 设备ID              |
| `temperature`      | float    | 温度（℃）           |
| `humidity`         | float    | 湿度（%）           |
| `light_intensity`  | float    | 光照强度（lux）     |
| `co2`              | float    | 二氧化碳浓度（ppm） |
| `soil_temperature` | float    | 土壤温度            |
| `soil_humidity`    | float    | 土壤湿度            |
| `ts`               | datetime | 采集时间            |

> 🔄 关联：通过 `device_id` 关联 `tb_site.iot_device_id`

---

### 3. `tb_address` —— 用户收货地址
用户在下单时选择的收货地址。

| 字段             | 类型    | 含义         |
| ---------------- | ------- | ------------ |
| `address_id`     | int     | 主键         |
| `user_name`      | varchar | 所属用户     |
| `address_detail` | varchar | 详细地址     |
| `phone`          | varchar | 联系电话     |
| `contact_name`   | varchar | 收货人姓名   |
| `is_default`     | tinyint | 是否默认地址 |

> 🔗 外键：`user_name` → `tb_user.user_name`

---

### 4. `tb_bank` —— 银行贷款产品
银行提供的农业贷款产品信息。

| 字段               | 类型    | 含义                 |
| ------------------ | ------- | -------------------- |
| `bank_id`          | int     | 主键                 |
| `bank_name`        | varchar | 银行名称             |
| `loan_type`        | varchar | 贷款类型（如种植贷） |
| `interest_rate`    | float   | 年利率               |
| `max_amount`       | decimal | 最高额度             |
| `repayment_period` | int     | 还款期限（月）       |

---

### 5. `tb_bank_user` —— 银行系统用户
银行内部操作员账号。

| 字段       | 类型    | 含义                  |
| ---------- | ------- | --------------------- |
| `user_id`  | int     | 主键                  |
| `username` | varchar | 登录名                |
| `password` | varchar | 密码（加密）          |
| `role`     | varchar | 角色（admin/auditor） |

> ⚠️ 注意：此表与 `tb_user` 无关，是银行独立系统。

---

### 6. `tb_discuss` —— 知识文章评论

| 字段           | 类型     | 含义       |
| -------------- | -------- | ---------- |
| `discuss_id`   | int      | 主键       |
| `knowledge_id` | int      | 关联文章ID |
| `user_name`    | varchar  | 评论人     |
| `content`      | varchar  | 评论内容   |
| `create_time`  | datetime | 评论时间   |

> 🔗 外键：
> - `knowledge_id` → `tb_knowledge.knowledge_id`
> - `user_name` → `tb_user.user_name`

---

### 7. `tb_expert` —— 专家信息

### 10. `tb_knowledge` —— 农业知识文章

| 字段           | 类型     | 含义                  |
| -------------- | -------- | --------------------- |
| `knowledge_id` | int      | 主键                  |
| `title`        | varchar  | 文章标题              |
| `content`      | text     | 正文                  |

# 🔗 三、表之间的关系图（核心关联）

```
tb_user ─┬─ tb_order (own_name)
         ├─ tb_address (user_name)
         ├─ tb_finance (user_name)
         ├─ tb_financing_intention (user_name)
         ├─ tb_question (questioner)
         ├─ tb_reserve (questioner)
         ├─ tb_shoppingcart (own_name)
         └─ tb_site (user_name)

tb_order ─┬─ tb_purchase_detail (order_id)
          └─ tb_sell_purchase (order_id)

tb_purchase ─┬─ tb_purchase_detail (purchase_id)
             └─ tb_sell_purchase (purchase_id)

tb_site ── iot_device_message (iot_device_id)

tb_knowledge ── tb_discuss (knowledge_id)

tb_bank ── tb_finance (bank_id)

tb_expert ─┬─ tb_knowledge (expert_name)
           ├─ tb_question (expert_name)
           └─ tb_reserve (expert_name)
```

# 🌟 四、项目六大功能模块总结

| 模块              | 功能说明                          | 核心表                                                       |
| ----------------- | --------------------------------- | ------------------------------------------------------------ |
| **1. 用户系统**   | 注册、登录、角色管理、积分信誉    | `tb_user`                                                    |
| **2. 物联网监控** | 实时采集温湿度、光照、CO₂等       | `amqp_message`, `iot_device_message`, `tb_site`              |
| **3. 金融服务**   | 贷款申请、融资意向、银行对接      | `tb_bank`, `tb_finance`, `tb_financing_intention`, `tb_bank_user` |
| **4. 电商交易**   | 发布商品/求购、购物车、下单、结算 | `tb_order`, `tb_shoppingcart`, `tb_purchase`, `tb_purchase_detail`, `tb_sell_purchase` |
| **5. 专家服务**   | 问答、预约、技术指导              | `tb_expert`, `tb_question`, `tb_reserve`                     |
| **6. 内容与行情** | 技术文章、市场价参考              | `tb_knowledge`, `tb_discuss`, `tb_price`                     |
